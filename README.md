## Soren / imcfyulong

把测试与分析做成可复用的工具。公开作品集中在 Android 安全测试、网络探测，以及多智能体应用。

### 研究方向

- **移动安全测试** — 把 APK 解包、反编译、组件分析和报告串成一条工作流。
- **网络探测工具** — 用 Python 复刻常用扫描能力。
- **多智能体应用** — CrewAI 编排加 RAG，带角色边界和报告输出。

### 代表项目

- [Android-pentest-mcp](https://github.com/imcfyulong/Android-pentest-mcp) — 基于 MCP 的 Android 安全测试工具集。接入后可以用一句话触发解包、反编译、组件分析、代码扫描、动态 Hook 和漏洞报告。Python，9 stars，1 fork。
- [pymap](https://github.com/imcfyulong/pymap) — Nmap 部分功能的 Python 复刻。1 star。
- [Cymate-CrewAIWithRag](https://github.com/imcfyulong/Cymate-CrewAIWithRag) — 长宜助手。医生 / 个人双角色，四个 Agent 顺序完成检索、非临床心理建议、双轨记忆和 PDF 报告，带高危话题升级边界。入口是 Streamlit 和 FastAPI。

### 公开数据

4 个公开仓库，10 stars，1 fork，1 follower。自有仓库语言都是 Python。

### 说明

安全测试相关工具只用于授权测试、防御研究和学习。
